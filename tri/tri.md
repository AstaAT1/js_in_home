## 1. Tri à Bulles — Bubble Sort

### الفكرة

Bubble Sort كيقارن كل مرة **جوج عناصر حداهُم**.

- إلا كان العنصر اللي فاليسار أكبر من اللي فاليمين → كنبدلوهم.
- كنكمّلو حتى لآخر الـ array.
- من بعد كنعاودو نفس العملية عدة مرات حتى تترتب الـ array كاملة.
- فكل passage، واحد من أكبر العناصر كيمشي تدريجياً لليمين حتى يوصل للبلاصة الصحيحة ديالو.

### مثال

البداية:

`[5, 3, 7, 1]`

Passage 1:

- `5` مع `3` → swap → `[3, 5, 7, 1]`
- `5` مع `7` → ما كاين والو
- `7` مع `1` → swap → `[3, 5, 1, 7]`

Passage 2:

- `3` مع `5` → والو
- `5` مع `1` → swap → `[3, 1, 5, 7]`

Passage 3:

- `3` مع `1` → swap → `[1, 3, 5, 7]`

### الفكرة اللي خاص تبقى فمخك

> **Bubble Sort = قارن الجيران، وبدلهم إلا كانوا مقلوبين.**

## 2. Tri par Insertion — Insertion Sort

### الفكرة

Insertion Sort كيقسم الـ array ذهنياً لجوج أجزاء:

- جهة على اليسار **مرتبة**
- جهة على اليمين **مازال ما ترتباتش**

فكل دورة:

1. كنشد عنصر من الجزء اللي مازال ما مرتبش.
2. كنخليه فـ `key`.
3. كنرجع لليسار ونقارن `key` مع العناصر المرتبين.
4. أي عنصر أكبر من `key` كنزحزحوه خانة لليمين.
5. منين نلقاو البلاصة المناسبة، كنحطو `key` فيها.

### مثال

البداية:

`[5, 2, 4, 6, 1]`

كنعتابرو `5` بوحدها مرتبة:

`[5 | 2, 4, 6, 1]`

ناخدو `2`:

`2 < 5`

إذن `2` تدخل قبل `5`:

`[2, 5 | 4, 6, 1]`

ناخدو `4`:

- `4 < 5` → 5 تزحزح لليمين
- `4 > 2` → نحط 4 من بعد 2

النتيجة:

`[2, 4, 5 | 6, 1]`

`6` أصلاً فبلاصتو:

`[2, 4, 5, 6 | 1]`

دابا `key = 1`:

- `1 < 6`
- `1 < 5`
- `1 < 4`
- `1 < 2`

كنزحزحوهم كاملين لليمين، ومن بعد نحطو `1` فالأول:

`[1, 2, 4, 5, 6]`

### الفكرة اللي خاص تبقى فمخك

> **Insertion Sort = شد عنصر، ورجّعو لليسار حتى يدخل فالبلاصة الصحيحة وسط الجزء المرتب.**

## 3. Tri par Sélection — Selection Sort

### الفكرة

Selection Sort كيدير فكل دورة حاجة وحدة:

> **كيقلب على أصغر عنصر فالجزء اللي مازال ما مرتبش.**

منين كيلقاه:

- كيخزن الـ index ديالو
- وكيبدلو مع أول عنصر فالجزء اللي مازال ما مرتبش

ومن بعد داك العنصر اللي دخل فاليسار كنعتابروه سالا وترتب.

### مثال

البداية:

`[29, 10, 14, 37, 13]`

أول دورة:

أصغر عنصر هو `10`

نديرو swap بين `29` و `10`:

`[10 | 29, 14, 37, 13]`

ثاني دورة:

كنقلبو غير فالجزء:

`[29, 14, 37, 13]`

أصغر عنصر هو `13`

swap:

`[10, 13 | 14, 37, 29]`

من بعد `14` راه أصغر واحد فالباقي:

`[10, 13, 14 | 37, 29]`

من بعد `29`:

`[10, 13, 14, 29, 37]`

### الفكرة اللي خاص تبقى فمخك

> **Selection Sort = قلب على الأصغر، وجيبو لأول بلاصة فالقسم اللي مازال ما مرتبش.**

## 4. Tri Rapide — Quick Sort

### الفكرة

Quick Sort كيختار واحد العنصر كنسميوه:

**Pivot**

ومن بعد كنقسمو العناصر:

- اللي أصغر من pivot → `left`
- اللي أكبر من pivot → `right`

من بعد كنعاودو نفس العملية على `left` و `right`.

ملي sub-array يكون فيها 0 ولا 1 عنصر، ما بقا فيها والو يترتب.

### مثال

البداية:

`[5, 2, 9, 3, 7]`

نختارو:

`pivot = 7`

كنقسمو:

- الأصغر من 7 → `[5, 2, 3]`
- pivot → `[7]`
- الأكبر من 7 → `[9]`

يعني:

`[5, 2, 3] | 7 | [9]`

دابا نخدمو على:

`[5, 2, 3]`

نختارو:

`pivot = 3`

كنقسمو:

`[2] | 3 | [5]`

كل جهة فيها عنصر واحد، يعني مرتبة.

نجمعو:

`[2, 3, 5]`

ومن بعد مع pivot الأول واليمين:

`[2, 3, 5] + [7] + [9]`

النتيجة:

`[2, 3, 5, 7, 9]`

### الفكرة اللي خاص تبقى فمخك

> **Quick Sort = Pivot → Left / Right → عاود نفس العملية على كل جهة → جمع النتيجة.**

## 5. Tri Fusion — Merge Sort

### الفكرة

Merge Sort عندو جوج مراحل كبار:

1. **Split**
2. **Merge**

### المرحلة 1: Split

كنقسمو الـ array على جوج، ومن بعد كل نصف على جوج، حتى تبقى كل array فيها عنصر واحد.

مثلاً:

`[34, 12, 5, 9, 42, 1]`

كتتقسم:

`[34, 12, 5]` و `[9, 42, 1]`

من بعد:

`[34] [12, 5]` و `[9] [42, 1]`

ومن بعد:

`[34] [12] [5] [9] [42] [1]`

دابا كل array فيها عنصر واحد، يعني كل وحدة مرتبة بوحدها.

### المرحلة 2: Merge

كنرجعو ندمجو جوج arrays مرتبين.

مثلاً:

`[1, 3]` و `[2]`

كنقارن أول عنصر باقي فكل array:

- `1` مع `2` → ناخدو `1`
- بقات `[3]` و `[2]`
- `3` مع `2` → ناخدو `2`
- بقات غير `3`

النتيجة:

`[1, 2, 3]`

مثال أكبر:

`[1, 1, 3, 4, 5]`

و:

`[0, 2, 3, 6, 7, 8]`

كنقارن كل مرة **أول عنصر مازال ما استعملناهش** من كل جهة:

- `1` مع `0` → 0
- `1` مع `2` → 1
- `1` مع `2` → 1
- `3` مع `2` → 2
- `3` مع `3` → 3
- من بعد 3 الثانية
- 4
- 5
- 6
- 7
- 8

النتيجة:

`[0, 1, 1, 2, 3, 3, 4, 5, 6, 7, 8]`

### الفكرة اللي خاص تبقى فمخك

> **Merge Sort = قسم حتى يبقى عنصر واحد، ومن بعد رجع دمج arrays مرتبين، وكل مرة خد الأصغر.**

مهم:

ماشي كنقارن `index 0` مع `index 0` و `index 1` مع `index 1`.

كنقارن دائماً:

> **أول عنصر باقي من الجهة اليسرى مع أول عنصر باقي من الجهة اليمنى.**

## 6. Tri par Comptage — Counting Sort

### الفكرة

Counting Sort مختلف على الطرق اللي قبل.

هنا:

- ما كنديروش swap
- ما كنقارنوش كل رقم مع رقم آخر

كنحسبو غير:

> **شحال من مرة جا كل رقم؟**

ومن بعد كنعاودو نبنيو الـ array من الرقم الأصغر للكبير.

### مثال

البداية:

`[1, 14, 14, 1, 1, 1, 2, 5, 3, 3, 15]`

كنحسبو:

- `1` جا 4 مرات
- `2` جا مرة
- `3` جا جوج مرات
- `4` جا 0
- `5` جا مرة
- ...
- `14` جا جوج مرات
- `15` جا مرة

ومن بعد كنبنيو array من الأصغر للكبير:

- 1 أربع مرات
- 2 مرة
- 3 جوج مرات
- 5 مرة
- 14 جوج مرات
- 15 مرة

النتيجة:

`[1, 1, 1, 1, 2, 3, 3, 5, 14, 14, 15]`

مهم:

Counting Sort **ما كيرتبش حسب شكون متكرر أكثر**.

التكرار غير كيقول لينا:

> شحال من نسخة خاصنا نكتب من داك الرقم.

أما الترتيب كيبقى حسب القيمة:

`1 → 2 → 3 → 4 → ...`

### الفكرة اللي خاص تبقى فمخك

> **Counting Sort = Count occurrences → rebuild sorted array.**

---

# الفرق السريع بين الخوارزميات

| Algorithm | الفكرة الرئيسية |
|---|---|
| Bubble Sort | قارن الجيران وبدلهم |
| Insertion Sort | دخل العنصر فالبلاصة ديالو فالجزء المرتب |
| Selection Sort | قلب على الأصغر وجيبو لأول بلاصة |
| Quick Sort | Pivot → Left / Right → Recursion |
| Merge Sort | Split → Merge مرتب |
| Counting Sort | Count occurrences → rebuild |

---

# كيفاش تفرق بينهم بسرعة؟

- **Bubble:** كتقارن `arr[j]` مع `arr[j + 1]`، يعني الجيران.
- **Insertion:** كتستعمل `key` وكتزحزح العناصر الكبار لليمين.
- **Selection:** كتستعمل `minIndex` وكتقلب على أصغر عنصر فالباقي.
- **Quick:** كتستعمل `pivot` وكتقسم لـ `left / pivot / right`.
- **Merge:** كتقسم، ومن بعد كتدمج جوج arrays مرتبين.
- **Counting:** كتحسب التكرارات، ومن بعد كتعيد بناء الـ array.
